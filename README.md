# 🍽️ 01. Zomato Exploratory Data Analysis

### 📌 Dataset
Zomato Restaurants Dataset

### 🔍 Project Focus

- Country-wise restaurant distribution analysis
- Customer rating and engagement analysis
- Identification of countries with zero ratings
- Rating classification using color categories
- City-wise restaurant concentration analysis
- Business-focused visual storytelling

### 📈 Key Outcomes

- Identified India as the dominant market in the dataset
- Observed strong correlation between ratings and customer engagement
- Highlighted regions with low or zero customer feedback
- Derived actionable business insights suitable for dashboards and reporting

### 🛠️ Skills Demonstrated

- Data Cleaning
- Data Visualization
- Statistical Analysis
- Exploratory Data Analysis
- Insight Generation

# 🚗 02. US Accident Data Analysis

### 📌 Dataset
US Accident Dataset (~1.5 Lakh+ Records)

### 🔍 Project Focus

- Large-scale accident data analysis
- Traffic accident trend identification
- Weather and environmental impact analysis
- Time-based accident pattern analysis
- State-wise and city-wise accident distribution
- Severity analysis and hotspot identification

### 📈 Key Outcomes

- Successfully handled and analyzed a large dataset containing over 1.5 lakh records
- Identified accident-prone regions and peak accident timings
- Discovered correlations between weather conditions and accident severity
- Generated analytical insights for traffic safety and urban planning

### 🛠️ Skills Demonstrated

- Large Dataset Handling
- Data Cleaning & Preprocessing
- Feature Analysis
- Time-Series Analysis
- Data Visualization
- Insight Extraction
- Analytical Thinking
