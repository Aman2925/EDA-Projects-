# 🚗 US Accident Data Analysis

A comprehensive **Exploratory Data Analysis (EDA)** project focused on analyzing large-scale US accident data to uncover traffic patterns, accident hotspots, environmental impacts, and time-based accident trends using Python and data visualization techniques.

This project demonstrates practical experience in handling **large real-world datasets (~1.5 Lakh+ records)** and transforming raw accident data into meaningful analytical insights.

---

# 📌 Project Overview

The objective of this project is to analyze accident trends across the United States and identify critical factors contributing to road accidents.

The analysis focuses on:

- Accident severity patterns
- State-wise and city-wise accident distribution
- Weather and environmental conditions
- Time-based traffic accident trends
- Accident hotspot identification
- Road safety insights

---

# 🎯 Business Problem

Road accidents lead to major economic losses, traffic disruptions, and safety concerns. Understanding accident behavior through data analysis can help improve traffic management, road planning, and public safety strategies.

This project addresses these challenges by:

- Identifying high-risk accident zones
- Analyzing accident frequency patterns
- Understanding environmental impacts on accidents
- Generating data-driven safety insights

# 📈 Key Insights Generated

- Certain states showed significantly higher accident frequency.
- Peak accident timings were observed during busy traffic hours.
- Weather conditions such as fog and rain contributed to increased accident severity.
- Urban regions experienced higher accident density compared to rural areas.
- Visibility and road conditions strongly impacted accident occurrence.
